# 管理者によるデータアクセス

位置履歴と写真は私的情報であり、運営者の自由な閲覧用途には使用しない。

- 不具合調査、復旧、削除依頼、セキュリティ事故対応のチケットを先に作る。
- 原則として座標・写真を含まないログ、集計、再現データを用いる。
- 実データが必要な場合は対象アカウント、期間、目的を限定し、依頼者の同意または対応根拠を記録する。
- アクセス者、日時、クエリ、持ち出しの有無、削除日を監査記録に残す。閲覧用コピーは調査終了後に削除する。
- service_role鍵をアプリ、共有ページ、チケットに掲載しない。管理権限は必要な担当者のみへ付与する。
- RLSとprivate bucketは維持する。ただしDB管理者の技術的な閲覧能力をRLSで完全に禁止するものではない。運用権限と監査を併用する。

公開前ゲート：正式な問い合わせ窓口、保管期間、管理担当者、規約・ポリシーの承認を確認する。
