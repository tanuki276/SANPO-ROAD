# CR11

基準: PR #10 / 527ff33808583894351698d80db12dc4fec1c7fa。

- 高精度GPSの1秒要求を維持。地図用の有効点を保存し、距離は精度依存のアンカー方式で別判定。accuracy × 1.25（最小移動量以上、最大12m）の範囲内は保留。3点以上の一貫した進行は早期採用。固定倍率補正なし。15秒超の欠測・一時停止を橋渡しして距離加算しない。
- GPS品質: 距離採用/除外、精度中央値、±10m超の観測時間、良好/普通/不安定。DEBUG時に有効な連続点間の生距離と積算距離を表示。最初のアンカーは距離0のため除外側に計上。重複時刻は集計対象外。品質と距離状態を点列と同じRoomトランザクションに保存。
- 移動/休憩/経過、標準/任意タグ、月別タグ集計。休憩は手動一時停止の時間で、自動停止判定ではない。
- Health Connect 1.1.0: セッション・距離、実際の休憩区間、権限別の歩数/心拍/カロリー集計。SANPO保存と独立。同じ散歩に安定したclientRecordIdを使用。結果・履歴地図から再試行。復元記録は書き込まない。旧記録で休憩区間がない場合は合計休憩をnotesに記載。削除はHealth Connect側で管理。
- ネイティブvectorの道＋肉球アイコン: 通常/round/adaptive/Android13 monochrome。
- 地図共有は始終点150m以内の全訪問を送信前に除去し、非表示区間はsegmentで分割。既存リンクには遡及しない。
- SANPO JSON（写真込み）とCR10のJSON配列を取り込み。形式/サイズ/座標/画像を検証、既存記録を上書きせず一括保存、同じバックアップは重複スキップ。ファイル指定の所有者・ローカルパス・importedフラグは信用しない。取り込み後は自己ベスト/累計/目標/連続日数/比較から除外。
- インポート由来は端末の保存・マージ・クラウド更新で保持。ただし改造APK/直接DB改ざんまで防ぐサーバー認証型の不正対策ではない。

## 配備
CR10とCR11のSQL移行が必要。本番DBへの自動適用は行わない。Health ConnectのPlay Console権限申告とプライバシーポリシー整合、署名付き配布は別途必要。

## 検証
GPS合成テスト、バックアップ/取り込み由来テスト、プライバシー境界・再訪問テスト、既存テストをCIで実行。実データ原本は未提供のため1.70km記録の再計算はしていない。端末実測で静止/低速/犬の折返し/休憩/再起動、Health Connectの拒否/取消/再試行/重複を確認する。
