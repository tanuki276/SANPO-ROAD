# アプリ改善の確認手順

## 自動確認

`gradle testDebugUnitTest assembleDebug`

履歴の空検索、名前とメモをまたぐ複数語検索、英字の大文字小文字、全角空白、距離・時間・日付の並び順、該当なし、入力リストの非破壊性を単体テストで確認します。

## 実機での受け入れ確認（要実施）

- Android 13 以降と Android 8〜12 で起動し、下部ナビゲーションを切り替える。戻る操作で散歩画面に戻る。
- ダーク／ライト、小さい画面、大きい文字、横画面で操作する。保存ダイアログはキーボード表示時にもスクロールできる。
- 位置情報の拒否／おおよその位置のみ／端末の位置情報オフで開始し、説明から設定へ進める。正確な位置情報を許可後に再度開始できる。
- GPS 未取得のまま終了した場合、保存が無効になり理由が表示される。破棄をキャンセルしても記録が残る。
- 屋外で記録し、距離・時間・GPS 精度、追従解除と再開を確認する。履歴・振り返りへの画面移動中も記録が続く。
- 通知許可／拒否をそれぞれ試す。許可時は通知をタップしてアプリへ戻れ、「散歩を終了」から保存待ちに進める。
- 名前・メモを入力して画面回転する。写真選択のキャンセルで既存の写真選択が消えない。写真を外して保存できる。
- ストレージ不足や写真アクセス失敗時に保存エラーを表示し、未保存の散歩が残る。再試行で重複保存しない。
- アプリを開き直して保存済みの距離・時間・道筋・写真・メモを確認する。
- 名前・メモ検索、検索解除、3 種類の並び順、該当なし表示、カード全体からの地図表示を確認する。
- オフラインで保存し、オンライン復帰後に右上の再同期を実行する。同期中は再同期ボタンが無効になる。

GPS、通知、権限、バックグラウンド動作は JVM 単体テストだけでは検証できません。

## GPS 記録の回帰確認

- 初回の推定精度が18〜25mでも記録が始まることを確認する。
- 屋外の同じコースで旧版と新版を比較し、曲がり角、ゆっくり歩行、5分静止の道筋と距離を確認する。
- 測位を一時的に失い、最後の記録地点から100m程度離れた場所で復帰しても記録が進むことを確認する。未測位区間は直線推定で、実際の経路は復元できない。
- 画面オフ・画面遷移・サービス再起動後の継続と、保存後の端末／クラウド／共有画面の一致を確認する。
- 1秒間隔の高精度要求による電池消費を30分の同一コースで旧版と比較する（OSや端末により実際の更新間隔は異なる）。
- 単体テストでは開始時精度、100m先での復帰、異常ジャンプ、時刻逆転・重複、静止揺れ、短距離移動、不正値、連続測定点の距離を確認する。コールバック配信と実測精度は実機確認が必要。
